# Siddharth & Muskan Wedding Invitation

A responsive, standalone wedding invitation website. Open `index.html` in a browser to view it. The artwork is stored locally in `assets/`; the map button opens Google Maps.

The event details come from the invitation page. Dress codes are labeled as suggestions because the source page does not publish dress codes.

## Hero photos

To add a photo, copy it into `assets/hero-gallery/` and add another `<img class="hero-slide" ... hidden>` inside `#hero-photos` in `index.html`. Set the relative image path and descriptive alt text. The order in the HTML is the order of the slideshow. The count, swipe navigation, and looping adjust automatically.
